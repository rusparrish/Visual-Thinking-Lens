# Teardown Stage Guide

Use this reference when a user asks for a full staged teardown, a next-stage prompt, or a diagnosis of where a teardown failed.

## Stage 0: Base

Purpose: locate the default.

Ask:

- What does the prompt/image do without pressure?
- What is the easy genre solution?
- What symbols are readymade?
- Where is the composition too balanced, centered, or polite?
- What looks finished but untested?

Typical verdicts:

- `untested`: competent, but no strain.
- `emblem`: subject announces meaning but does not investigate it.
- `decorative`: atmosphere substitutes for consequence.
- `stable`: base has usable structure and can enter Probe.

Prompt pattern:

```text
[Plain subject/scene], rendered clearly enough to reveal its default composition, symbols, light, and narrative assumptions. Avoid adding rupture yet.
```

## Stage 1: Probe

Purpose: test whether the base contains internal constraint.

Add one to three pressures:

- oblique view through a door, mirror, screen, window, or partial obstruction
- conflicting light sources
- blocked central subject
- scale pressure
- a second object that acts as witness
- floor, wall, or frame that tilts against the subject
- absence where the expected narrative answer should be

Good Probe behavior:

- pressure changes the scene's logic
- the subject is no longer merely displayed
- light, space, or object relation assigns consequence
- the image becomes less illustrative and more implicated

Bad Probe behavior:

- extra clutter
- generic darkness
- decorative surrealism
- cinematic mood without structure

Prompt pattern:

```text
[Medium/scene]. Keep [base subject], but introduce [specific pressure]. Let [space/light/object/gesture] fracture the easy read. The image should test whether [core idea] can carry tension without becoming decorative.
```

## Stage 2: Yield

Purpose: make the strongest pressure answer back.

Yield is not refinement. It is a counter-response that validates or redirects the Probe.

Use when:

- Probe created real tension.
- There is a visible pressure point worth compressing.
- The idea can survive a stricter condition.

Yield tactics:

- shift from subject drama to architectural consequence
- move light away from the obvious target
- enlarge the witness object
- pause the central gesture
- make the background become the pressure system
- compress the scene so nothing escapes

Prompt pattern:

```text
[Medium/scene]. Preserve [strongest pressure from Probe], but redirect it through [counter-condition]. Let [specific element] become load-bearing. Avoid spectacle; the tension should narrow, not explode.
```

Verdicts:

- `viable contradiction`: pressure became structure.
- `false yield`: image became prettier or more theatrical.
- `too literal`: the prompt obeyed the symbol but missed the condition.
- `return to Probe`: tension is not yet earned.

## Stage 3: Collapse Echo

Purpose: rupture the logic when the Yield over-resolves, collapses into polish, or refuses contradiction.

Collapse Echo is a diagnostic failure prompt. It should break narrative symmetry in a controlled way.

Use pressure types:

- misaligned reflection
- doubled object with different temporal meaning
- floating-but-believable object relation
- inconsistent warm/cold light
- repeated motif that starts to lose its original function
- architecture that compresses or watches the subject
- form that refuses to cohere but remains legible

Prompt pattern:

```text
[Medium/scene]. Preserve the recognizable scene, but let [specific contradiction] breach its logic. Nothing should become random; the failure must reveal [what the idea cannot hold]. Let form and light refuse to fully cohere while remaining visibly intentional.
```

Verdicts:

- `productive fracture`: failure shows a useful next pressure.
- `chaos`: rupture is random and should be rebuilt.
- `overload`: too many contradictions at once.
- `closure return`: model repaired the rupture into harmony.

## Stage 4: Suspended Opposition

Purpose: fuse stable contradictions without resolving them into compromise.

This is not a happy ending. It is a held state where two pressures remain active.

Use when:

- Probe produced structure.
- Yield found a viable counter-condition.
- Collapse Echo revealed the failure boundary.
- There are two strong logics to hold at once.

Suspension tactics:

- remove clutter after rupture, but keep the cause of pressure
- let light connect objects without explaining them
- preserve one contradiction in a quieter form
- make poise carry fracture rather than erase it
- keep the reason ambiguous

Prompt pattern:

```text
[Medium/scene]. Recombine [pressure A] and [pressure B] into a restrained image. Do not harmonize them. Let [specific element] hold memory of the rupture while [specific stabilizer] keeps the scene legible. The result should feel poised but unresolved.
```

Verdicts:

- `held opposition`: tension remains visible without chaos.
- `quiet closure`: image became safe again.
- `compromise`: both pressures weakened each other.
- `return to Collapse Echo`: contradiction was neutralized too early.

## Full Teardown Acceptance Checks

A teardown is working when:

- each stage changes the image's logic, not just its mood
- one or more symbols become structural devices
- the image gives up some polish to gain consequence
- failure reveals a specific next move
- final suspension remains unresolved without becoming incoherent

A teardown is failing when:

- the prompts only add adjectives
- darkness or surrealism is used as a shortcut
- every stage looks like the same image with more drama
- symbols remain props
- final output becomes balanced, cozy, or explanatory
